# Generalization

Add this script on first boot:

```bash
dnf autoremove -y && dnf clean all -y && dnf update -y

truncate -s 0 /etc/machine-id
rm -f /etc/machine-id
systemd-machine-id-setup

rm -f /etc/ssh/ssh_host_*

journalctl --rotate
journalctl --vacuum-time=1s
rm -rf /var/log/*

history -c
rm -rf /home/*/.bash_history

fstrim -av


# Execute on first boot
systemd-machine-id-setup

fstrim -av && history -c && clear
```
